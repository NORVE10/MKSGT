# MKSGT site

- The whole site is `index.html`, with no build step. Topics, students, colors and background icons are in the `TOPICS` list near the bottom; the icon SVGs are inlined in `ICONS` (Phosphor Icons, MIT).
- GitHub Pages serves `main` at https://norve10.github.io/MKSGT/.
- The owner asked for changes to go live directly: commit and push to `main`, no pull request.
