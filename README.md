# INTERLINK-MKSGT EPP LEVEL 6

Think, Create, Change. A class writing project in English: twenty students, twenty topics.

**Live site:** https://norve10.github.io/MKSGT/

## Editing

Everything is in `index.html`. The `TOPICS` list near the bottom of the file holds each topic, the student writing it, its color and its background icons.

تعديل الموقع: كل شي داخل ملف `index.html`. قائمة `TOPICS` تحت في الملف فيها كل موضوع واسم الطالب واللون والأيقونات.

Icons: [Phosphor Icons](https://phosphoricons.com) (MIT license).
